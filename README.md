# SME Cybersecurity Advisory Platform

## Project Overview

This capstone project aims to develop a web-based advisory platform that helps SMEs assess their cybersecurity readiness and identify suitable Bitdefender GravityZone solutions based on their organisation's environment and security needs.

The platform is intended to support both customers and internal sales or technical teams during the cybersecurity solution recommendation process.

## Problem Statement

**How can we simplify cybersecurity readiness assessment and Bitdefender solution recommendations for SMEs?**

## Objectives

* Develop a cybersecurity readiness assessment for SMEs
* Identify potential cybersecurity gaps
* Recommend suitable Bitdefender GravityZone solutions
* Integrate selected Bitdefender GravityZone API functions
* Present assessment results and recommendations through a web interface

## Planned Features

* Organisation profile assessment
* Cybersecurity readiness questionnaire
* Readiness scoring
* Security gap identification
* Bitdefender solution recommendation
* GravityZone API integration
* Assessment results dashboard
